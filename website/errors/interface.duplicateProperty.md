title: "interface.duplicateProperty"
ignorable: false
---

## Code example

```php
<?php declare(strict_types = 1);

// This identifier is produced by the DuplicateDeclarationRule which uses the
// class type description as prefix. In practice, interfaces cannot have
// properties, so this identifier is unlikely to be encountered in valid PHP code.
// The rule applies uniformly to all class-like declarations.

class Foo
{
	public string $name;
	public string $name;
}
```

## Why is it reported?

The declaration contains the same property name more than once. PHP does not allow redeclaring a property within the same class body. This will cause a fatal error at runtime.

While the `interface.` prefix suggests this applies to interfaces, this identifier is generated by a generic rule that prefixes the error with the class-like type description. Interfaces cannot have properties in PHP versions before 8.4, so this error is primarily relevant to classes (where the identifier would be `class.duplicateProperty`).

## How to fix it

Remove the duplicate property declaration or rename it:

```diff-php
 <?php declare(strict_types = 1);

 class Foo
 {
 	public string $name;
-	public string $name;
+	public string $label;
 }
```
